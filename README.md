## 🚀 Key Accomplishments & Tools

* 🛡️ **SAGE**: Designed and developed a GitHub-based security search automation tool to scan repositories proactively for recurring vulnerability anti-patterns and unsafe code structures.
* 🔌 **Custom Burp Suite Tooling**: Built proprietary Burp Suite extensions and testing workflows to accelerate API/Web input validation discovery and bypass validation layers.
* ☁️ **CI/CD Security Pipelines**: Integrated automated SAST, DAST, and SCA scanning (Snyk, SonarQube, Qualys, Mend) within Jenkins environments to validate release cycles continuously.
* 🔍 **Enterprise Source Code Reviews**: Conducted hundreds of white-box reviews for critical Java/Spring Microservices, identifying authorization flaws, deserialization bugs, and injection risks.
